Broadcast Graphics Live v0.8.13-alpha — Development Version 403

Implemented changes
- Layer-list row numbers now inherit the recalculated background-aware WindowText palette role instead of freezing a stylesheet color.
- The 2D/3D control is recalculated from the actual composited row background. In the 2D state it uses the row foreground; the active 3D state keeps the OBS Highlight surface and a matching highlighted foreground.
- Background-aware foreground selection now switches to the dark semantic OBS palette candidate only at relative luminance >= 0.42. Medium colors therefore retain light UI content.
- Blend-mode dropdown entries are text-only; the repeated timeline-modes.svg item icons were removed.
- Audio-layer waveforms and linked video audio-stream waveforms use the opposite dark/light semantic palette candidate from strip labels and layer-type icons.
