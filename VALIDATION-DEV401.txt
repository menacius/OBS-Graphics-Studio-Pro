Development Version 401 — Background-aware layer UI
Validation date: 2026-07-20

IMPLEMENTED SCOPE

1. Layer-list rows
   - The effective unselected row background is computed by compositing the
     layer color at alpha 72 over the active OBS Window palette color.
   - Selected rows use the opaque layer color.
   - Text, carets, visibility/audio/lock/matte controls, blend-mode icons and
     other row controls choose a dark or light semantic foreground from the
     active OBS palette by comparing relative luminance and contrast.
   - Selection changes immediately refresh row palettes and icon tinting.
   - OBS PaletteChange, ApplicationPaletteChange and StyleChange rebuild the
     row UI using the new theme palette.
   - Combo-box popup views remain on their normal opaque OBS theme surfaces.

2. Layer-type cells
   - Supplied layer-type SVGs can be rendered with an explicit foreground.
   - The icon/fallback abbreviation inside the colored type chip chooses its
     foreground against the chip's own authored/default layer color.
   - Rendered icon variants are cached by icon name and RGBA foreground.

3. Timeline strips
   - Each strip now displays its layer-type icon before the layer name.
   - Strip label, icon, waveform, progress detail, fade curves, lock hatching
     and outline use a foreground selected against the final strip color.
   - Disabled/hidden labels use a muted blend derived from the same contrast
     foreground.
   - Transition overlays evaluate their alpha-composited color over the host
     strip before choosing hatch, handle and label foregrounds.
